# Movie-Recommendation-Engine-Using-Collaborative-Filtering
Movie Recommendation Engine using Collaborative Filtering

📌 Overview
This project builds a movie recommendation system using collaborative filtering techniques. It analyzes user ratings to predict preferences and suggest personalized movie recommendations.

Dataset: MovieLens Latest Small (100,000+ ratings from 600+ users on 9,000+ movies).


🚀 Features
✅ Memory-Based Collaborative Filtering

User-User similarity

Item-Item similarity

✅ Model-Based Collaborative Filtering

Matrix Factorization (SVD)

✅ Neural Collaborative Filtering

Deep learning-based recommendations

✅ Evaluation Metrics

RMSE, Precision@K, Recall@K

✅ Streamlit Deployment (Optional)

Interactive web interface

🛠️ Technologies Used
Python


Libraries:

pandas, numpy, scipy (Data Processing)

scikit-learn (SVD, Cosine Similarity)

TensorFlow/Keras (Neural CF)

matplotlib, seaborn (Visualization)

Streamlit (Deployment)
